# LCARS 用药助手 · MedPad

一个装在手机上、**完全离线**、星际迷航 LCARS 风格的吃药管理工具。
纯网页（PWA），不联网、不需要账号、不上传任何数据。

> 本 App 是记录与计算工具，**不是医疗器械，不提供用药建议**。
> 剂量调整、漏服怎么补，请以你的医生、药师和药品说明书为准。

## 一、它怎么对上你的五条需求

| 你的需求 | App 里的实现 |
| --- | --- |
| 随时加药 / 删药，名字 + 图标好辨认 | 「药品」页右下角 ＋ ；16 个图标 + 6 种颜色，卡片一眼区分；编辑页可改名、换图标、备注 |
| 算清每种药吃到哪天、起止日期 | 每种药卡片上直接写：起服日、**每天几片**、**盒里还有几片**、**预计哪天吃完**、建议哪天去补药 |
| 提醒 + 打卡 | 每天按时段列出要吃的药，一键 ✓ 打卡（可记「只吃了一半」「跳过」）；可导出 .ics 进手机日历当闹钟；页面开着时还会弹系统通知 |
| 自定义：每盒几片、早中晚各几片 | 每盒片数、散片、剂量精确到 **¼ 片**（0.25/0.5/0.75/1.5 都行）、四个时段可改时间、可开关、可按周几吃、可设暂停区间、可设医生要求的结束日期 |
| UI 美观清晰 | LCARS：纯黑底 + 琥珀/天蓝/丁香色块，超大字，按钮 ≥48px，深色不刺眼，夜间看不累 |

另外还有：7 天依从率统计、补药预警（剩余不足 N 天变琥珀色）、数据导出备份、导入恢复。

## 二、装到手机上（三选一）

### 方式 A：数据线一键装（推荐，**不需要任何账号**，装完可离线）

前提：一台 Windows 电脑 + 一根数据线 + 手机能连电脑。

1. 手机上打开「开发者选项」和「USB 调试」：
   - 设置 → 关于手机 → 连点「版本号」7 次
   - 回到 设置 → 系统 → 开发者选项 → 打开「USB 调试」
2. 用数据线把手机连到电脑，手机弹出「允许 USB 调试吗？」→ 勾「始终允许」→ 允许
3. 在电脑上右键 `tools\install-via-usb.ps1` →「使用 PowerShell 运行」
   （第一次会自动下载官方 adb，约 8MB）
4. 手机上会自动跳出浏览器，打开 App：
   - 等界面出现 → 点 Chrome 右上角菜单 →「添加到主屏幕 / 安装应用」
   - 从桌面图标打开一次，等 3~5 秒（让离线缓存落盘）
5. 回到电脑窗口按回车关闭 → 拔数据线、关电脑 → **手机仍然能正常用**

> **从 1.0 升级到 2.0**：装好之后手机浏览器里连续刷新两次（第一次把新版本拉进缓存，第二次换上新界面）。
> 你之前录入的药品与打卡记录都会保留，不用重录。

> 为什么这样能离线：手机访问的是 `http://localhost:8787`，这属于浏览器认可的「安全上下文」，
> 所以既能安装、又能被 Service Worker 完整缓存。装完之后 App 的代码已经在手机里了。

### 方式 B：免费静态托管（需要注册一个账号，最稳）

适合：电脑不方便一直开着，或者想给别的手机也用。

1. 注册任意免费静态托管（Netlify Drop / Cloudflare Pages / Vercel 都行，免费额度足够）
2. 把项目里的 `dist/` 文件夹（或整个项目）拖进上传框，得到一个 `https://xxx` 网址
3. 手机浏览器打开这个网址 → 菜单 →「添加到主屏幕」
4. 之后即使断网也能打开已缓存的版本

> 注意：这是一种「网页 App」。如果清空浏览器数据，本地记录也会消失 ——
> 所以用「设置 → 导出备份」定期存一份 JSON，永远是最后一道保险。

### 方式 C：同一 Wi-Fi 临时用（电脑必须开着）

1. 电脑上双击 `tools\start-server.ps1`，窗口里会打印「局域网地址」，形如 `http://192.168.1.5:8787`
2. 手机连同一个 Wi-Fi，浏览器打开这个地址
3. 能正常用，但**需要电脑一直开着**，只适合临时体验

## 三、第一次打开后建议做这三件事

1. 左下「药品」→ ＋ → 填名字、选图标、填**每盒几片**、勾上早/中/晚/睡前各吃几片 → 保存
   （卡片会立刻算出「每天 X 片、还剩 Y 天、预计 M 月 D 日吃完」）
2. 「设置」→ 把「提前几天提醒补药」设成你方便去开药的天数（默认 7 天）
3. 「设置」→ 导出备份，存到网盘或发给自己一份

药品没带在身边时不必精确到片：把「每盒几片」和「还剩几盒」填对，天数就不会差。

## 四、它是怎么算的（你可以自己核对）

- 内部把 1 片拆成 **4 份**（¼ 片），全部用整数运算，所以 0.5 片、0.25 片永远不会出现 0.30000000004 这种误差。
- **每天总量** = 各时段剂量之和（只算被打开、且当天符合周几规则的时段）。
- **消耗规则**（决定「还剩几片」）：
  - 从「开始吃的那天」到今天逐天扣减；
  - 今天：只有你打卡了才算吃掉（记录「已服」按全量、「一部分」按实际量、「跳过/漏服」按 0）；
  - 今天以前：没有记录的日期按「按时吃了」处理；你事后把某天标成「跳过」或「漏服」，药会自动回到库存里；
  - 暂停区间内的日子不扣药。
- **哪天吃完** = 从今天起往后逐天累加，直到剩余量不够当天剂量。剩余量刚好用完那天就是「吃完日」。
- **建议补药日** = 吃完日 −「提前提醒天数」。少于这个天数卡片会变成琥珀色告警。

举例（也是自测用例）：每盒 28 片 × 3 盒 = 84 片；早 1 片、晚 0.5 片 → 每天 1.5 片 → 84 ÷ 1.5 = **56 天**。
如果改成早 0.5 片，则每天 1 片 → **84 天**。

## 五、数据与隐私

- 所有数据只存在**你这台手机**的浏览器里（localStorage），不联网、不上传、无账号。
- 「设置 → 导出备份」得到一个 JSON 文件，里面是全部药品与打卡记录；
  「导入备份」可以原样恢复（换手机、清缓存前一定要导）。
- 用「导出到日历 (.ics)」可以把提醒导进手机自带日历 —— 这是**最可靠**的提醒方式，
  因为日历的闹钟即使 App 没打开也会响。
- 页面开着（切到后台但没关掉）时，App 也能自己弹系统通知；完全关掉后网页通知就不再触发，
  所以长期提醒还是推荐用日历。

### 升级安全（1.0 → 2.0）

- 数据仍然存在同一个 `localStorage` 键（`lcars_medpad_v1`）里，2.0 只是**增加字段**，不会清空。
- 第一次用 2.0 打开时，会把当时的数据原样另存一份到 `lcars_medpad_v1.bak`（只写一次，不会被覆盖）。
- 如果发现哪里不对，「设置 → 数据 → 恢复升级前的备份」可以退回去（退之前会自动先导出当前数据）。

## 六、目录结构

```
index.html              入口
app.css                 LCARS 样式（自写，非原版模板）
app.js                  界面、存储、打卡、导入导出
js/core.js              纯计算核心（无 DOM，可单独测试）
sw.js                   Service Worker：离线缓存
manifest.webmanifest    安装成 App 所需信息
icons/                  图标（由 tools/make_icons.py 生成）
assets/fonts/           Antonio 字体（LCARS 风格标题）
tools/serve.mjs         零依赖本机服务器
tools/start-server.ps1  一键启动服务器
tools/install-via-usb.ps1  一键装进安卓手机
tools/make_icons.py     重新生成图标
tests/core.test.mjs     计算逻辑测试（25 项，含「多吃」「出行药量」与依从率）
tests/ui.smoke.mjs      假 DOM 渲染测试（17 项，含舰况/红警/菜单/迁移/出行药量）
dist/                   可整包上传的发布版本
```

跑测试（无需安装任何依赖）：

```
node tests/core.test.mjs
node tests/ui.smoke.mjs
```

改了代码想立刻生效：把 `sw.js` 里的 `CACHE` 名字改一下（如 `medpad-v2`），
手机上下次打开就会拿新版本，旧缓存自动清掉。

## 照片打卡（v17 新增）

打卡面板底部多了「📷 照片存证」：

- **拍一张**：直接调手机相机；**从相册选**：挑已经拍好的。
- 照片会自动缩到最长边 720px 的 JPEG（一张约 40–80KB），存进浏览器的 IndexedDB。
- **环形缓冲区，只保留当天**：每次打开 App 会把不是今天的照片清掉；同一天最多留 24 张，超出按时间丢最旧的。所以它永远不会把手机塞满，也永远不会把上周的隐私留在相册外。
- 今天已拍的打卡，卡片上会多一个 📷，点它就能看大图（带拍摄时间）、也能删。
- 换手机 / 清缓存前记得先「导出备份」——照片不进 JSON 备份，只在本机。

### 手机上的老图标怎么办

现在的图标打开的是 `http://localhost:8787`（靠数据线隧道，拔线就打不开——这就是你看到
`ERR_CONNECTION_REFUSED` 的原因）。GitHub Pages 部署好后，**用新网址重新「添加到主屏幕」一次**，
再长按删掉旧图标即可。旧数据在浏览器里，删图标不会清掉；但换到新网址等于换了「站点」，数据不共享，
所以先在旧 App 里 **设置 → 导出备份（.JSON）**，到新网址里 **从备份导入** 一次。
